# 🎂 Siva Nandhini's Personalized Birthday Surprise Web App 💕

A digital birthday surprise web application made with love, care, and attention to detail by **Abishek** for **Siva Nandhini**.

Built as a lightweight, single-page web app with **HTML5, CSS3, and JavaScript** — zero frameworks or server backends required! Runs immediately offline or online on any phone, tablet, or desktop browser.

## 🎵 Audio Experience

- Dual-layer audio engine:
  1. Soft romantic instrumental / gentle lofi piano track.
  2. **Built-in Web Audio API Synthesizer**: If offline or if external audio is blocked, a custom ambient music box generates soothing arpeggiated piano chords (Cmaj7 - Am7 - Dm7 - G7) dynamically in JavaScript!
  3. Interactive procedural sound effects for balloon pops, candle blowing, envelope rustle, and celebration confetti.
  4. Floating music toggle button with spinning vinyl note indicator in the top-right corner.

## 🚀 How to Run & Share

### Option 1: View Locally on PC or Mac
Simply double-click `index.html` to open it directly in Chrome, Safari, Edge, or Firefox.

### Option 2: Run a Local Dev Server (Optional)
If you have Python installed:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

### Option 3: Host Online for Free (Send her a link!)
To send this surprise as a link to Siva Nandhini on WhatsApp, Instagram, or iMessage:
1. **GitHub Pages**:
   - Push this folder to a GitHub repository.
   - Go to **Settings > Pages > Branch: main > Save**.
   - Your live link will be ready in 60 seconds (e.g., `https://abishek.github.io/birthday-nandhini`).
2. **Netlify Drop**:
   - Go to [app.netlify.com/drop](https://app.netlify.com/drop).
   - Drag and drop this entire `Nandhini1` folder.
   - It will give you a free instant URL to send her right away!
